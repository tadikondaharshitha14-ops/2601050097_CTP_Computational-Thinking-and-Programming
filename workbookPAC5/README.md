**Banking Management System using Inheritance and Abstraction**

**1. Objective**

To develop a simple Python-based Banking Management System demonstrating inheritance, abstraction, and full type hints.

**2. Input**

The program accepts:

Customer name

Account number

Initial balance

Account type

Deposit amount

Withdrawal amount

**3. Output**

The program displays:

Customer details

Account details

Account type

Deposit result

Withdrawal result

Current account balance

**4. Algorithm**

Start.

Create an abstract BankAccount class.

Define common account methods using abstraction.

Create child classes such as SavingsAccount and CurrentAccount.

Use inheritance to reuse the properties and methods of BankAccount.

Use full Type Hints for variables, parameters, and return values.

Create a bank account for a customer.

Perform deposit operation.

Perform withdrawal operation.

Display the customer and account details.

Display the final balance.

Stop.

**5. Time and Space Complexity**

Time Complexity

Deposit = O(1)

Withdrawal = O(1)

Balance Check = O(1)

Space Complexity

O(n)

Where n is the number of bank accounts stored in the system.

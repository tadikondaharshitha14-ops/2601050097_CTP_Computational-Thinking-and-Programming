**AI-Assisted Code Review, Refactoring and Testing**

**1. Objective**

To perform AI-assisted code review, refactoring, and testing of a Python project and identify where AI succeeded and where manual intervention was required.

**2. Input**

The program accepts:

Two numbers

An operation such as addition or multiplication

**3. Output**

The program displays:

Calculation result

Test results

Code improvements suggested by AI

**4. Algorithm**

Start.

Review the Python code using AI.

Refactor the code based on AI suggestions.

Create and run tests.

Check AI suggestions manually.

Document AI successes and manual changes.

Stop.

**5. Time and Space Complexity**

Time Complexity: O(1)

Space Complexity: O(1)

**6. AI Success**

AI reviewed the Python code.

AI suggested better code organization.

AI helped with refactoring.

AI helped create test cases.

AI helped identify that the code works correctly.

**7. Manual Changes / Intervention**

Checked the AI suggestions manually.

Verified the program by running python app.py.

Ran python -m pytest.

Confirmed that 2 tests passed.

Accepted only the useful AI suggestions.

**Student/Employee Data Model using Dataclasses**

**1. Objective**

To implement a simple Student/Employee data model using Dataclasses and compare it with a traditional Python class.

**2. Input**

The program accepts:

Student/Employee name

ID

Age

Course/Job role

**3. Output**

The program displays:

Student/Employee details using Dataclass

Student/Employee details using Traditional Class

Comparison between both implementations

**4. Algorithm**

Start.

Create a Student/Employee class using @dataclass.

Define the required attributes with type hints.

Create objects using the Dataclass.

Create another Student/Employee using a traditional Python class.

Define the constructor manually in the traditional class.

Create objects using the traditional class.

Display the details of both objects.

Compare both implementations based on code simplicity and readability.

Stop.

**5. Comparison and Complexity**

Dataclass

Less code

Automatically provides a constructor

Easy to read and maintain

Supports Type Hints

Traditional Class

Requires a manual constructor

More code is required

Gives more control over implementation

**Time Complexity**

Object creation = O(1)

Accessing attributes = O(1)

**Space Complexity**

O(n)

Where n is the number of Student/Employee objects.

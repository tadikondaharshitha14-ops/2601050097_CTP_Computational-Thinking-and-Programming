**Python Application using AI-Assisted Development**

**1. Objective**

To develop a simple Python application using GitHub Copilot, Cursor, or Claude Code with specification-first development and AI-assisted documentation.

**2. Input**

The program accepts:

Student name
List of student marks

**3. Output**

The program displays:

Student name
Average marks
Student grade
AI-generated documentation and code assistance

**4. Algorithm**

Start.

Write the application requirements/specification.

Create the Python project.

Use GitHub Copilot/Cursor/Claude Code to generate the Python code.

Enter the student name and marks.

Calculate the average marks.

Determine the grade based on the specification.

Display the student details and grade.

Use AI assistance to create and improve documentation.

Test the application.

Stop.

**5. Time and Space Complexity**

**Time Complexity**

O(n)

Where n is the number of marks.

**Space Complexity**

O(n)

The marks are stored in memory.

**Specification-First, Type-Driven and Test-First Development with AI**

**1. Objective**

To develop a simple Python program using specification-first, type-driven, and test-first development with AI assistance.

**2. Input**

Two integer numbers.

**3. Output**

The sum of the two numbers.

**4. Algorithm**

Start

Write the specification.

Create the test first.

Write the Python code with type hints.

Run the test using pytest.

Use AI to review the code.

Verify the result.

Stop

**5. Time Complexity**

O(1) — Only two numbers are added.

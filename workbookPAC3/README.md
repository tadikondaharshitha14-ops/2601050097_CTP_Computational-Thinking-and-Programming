**Stack and Queue using Type Hints and Dataclasses**

**1. Objective**

To develop a reusable Python package that implements Stack and Queue using Type Hints and Dataclasses.

**2. Input**

The program accepts:

Elements for Stack

Elements for Queue

Stack operations: Push and Pop

Queue operations: Enqueue and Dequeue

**3. Output**

The program displays:

Stack elements

Queue elements

Popped element from Stack

Dequeued element from Queue

Final Stack and Queue

**4. Algorithm**

Start.

Create a Stack using a dataclass.

Use push() to add elements to the Stack.

Use pop() to remove elements from the Stack.

Create a Queue using a dataclass.

Use enqueue() to add elements to the Queue.

Use dequeue() to remove elements from the Queue.

Use Type Hints to specify the data types.

Display the Stack and Queue results.

Stop.

**5. Time and Space Complexity**

Time Complexity

Stack:

Push = O(1)
Pop = O(1)

Queue:

Enqueue = O(1)
Dequeue = O(1)

Space Complexity

O(n)

Where n is the number of elements stored in the Stack or Queue.

**List-Based vs Generator-Based Processing**

**1. Objective**

To compare list-based processing and generator-based processing for a large dataset in terms of execution time and memory usage.

**2. Input**

The program accepts:

A large dataset

Number of elements in the dataset

**3. Output**

The program displays:

List processing execution time

Generator processing execution time

List memory usage

Generator memory usage

Comparison of both methods

**4. Algorithm**

Start.

Create a large dataset.

Process the dataset using a list.

Measure the execution time and memory used by the list.

Process the same dataset using a generator.

Measure the execution time and memory used by the generator.

Compare the execution time of both methods.

Compare the memory usage of both methods.

Display the results.

Stop.

**5. Time and Space Complexity**

Time Complexity

List Processing = O(n)

Generator Processing = O(n)

Where n is the number of elements in the dataset.

Space Complexity

List Processing = O(n)

Generator Processing = O(1)

The list stores all elements in memory, while the generator produces one element at a time.
